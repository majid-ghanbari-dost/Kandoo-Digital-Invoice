# E-43 — نگاشت read-only از Holoo

**وضعیت: BLOCKED / NOT STARTED — gate پیش‌نیازها پاس نشده است**

E-43 مورد STRETCH است و فقط پس از تکمیل MUSTها مجاز به اجرای نگاشت read-only است. E-40 هنوز به‌دلیل نبود مشخصهٔ هنجاری Canonical v1.1، و E-42 به‌تبع آن، BLOCKED هستند؛ بنابراین شرط ورود به E-43 برقرار نیست و هیچ خواندن، parse، join، نگاشت یا آزمون روی sampleهای Holoo در این تسک انجام نشد.

پیش‌تر اندازه و SHA-256 هر ۱۰ فایل تحویلی به‌صورت hash-only با جدول اصلاحیه تطبیق داده شده بود؛ محتوای CSV خوانده یا نمایش داده نشد. این تطبیق به‌تنهایی مجوز مصرف نمونه در E-43 نیست. پس از عبور همهٔ MUSTها، دامنهٔ مجاز E-43 همان چهار reference sample اصلاح‌شده است؛ sampleهای قدیمی `*-2.csv` فقط برای مقایسه‌اند و نباید وارد آزمون شوند. هیچ‌یک از این ورودی‌ها در این گزارش کپی یا تغییر داده نشده است.

برای بازگشایی E-43، ابتدا E-40 و E-42 باید با مرجع Canonical v1.1 مصوب به نتیجهٔ PASS برسند؛ سپس فقط مسیر read-only و چهار reference sample تأییدشده قابل استفاده‌اند. تا آن زمان هیچ mapping یا نتیجهٔ ساختاری/عددی به E-43 نسبت داده نمی‌شود.
