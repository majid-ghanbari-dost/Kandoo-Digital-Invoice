# E-42 — سابقهٔ blocker تاریخی

**این وضعیت تاریخی است و دیگر وضعیت جاری E-42 نیست.** یادداشت قبلی بر فرض مسدودبودن E-40 بنا شده بود؛ پس از پذیرش E-40 و GO مدیر برای E-42، این مانع superseded شد. هیچ‌یک از یادداشت‌های قبلی مجوز استفاده از fixture واقعی برای E-42 نمی‌دهد.

وضعیت اجرا، تعریف سنجه، مرزهای synthetic-only، روش گزارش per-layout و زمان Windows در [`E-42-synthetic-accuracy-harness.md`](E-42-synthetic-accuracy-harness.md) ثبت شده است. کد harness در `scripts/run_e42_synthetic_accuracy_harness.py` قرار دارد. این فایل فقط برای حفظ ردیف تاریخی blocker نگه داشته شده است؛ به‌عنوان نتیجه یا تصمیم جاری استفاده نشود.
