# E-42 — harness و جدول دقت عددی

**وضعیت: BLOCKED — معیار v1.1 تعریف نشده است**

E-42 باید خروجی عددیِ تکرارپذیر و جدول metrics برای پشتیبانی Canonical Invoice v1.1 و نمونه‌های synthetic ارائه کند. پیش‌نیاز Canonical v1.1 در E-40 به‌دلیل نبود مرجع هنجاری BLOCKED است (شرح جست‌وجو و فایل‌های مرجع: `docs/E-40-canonical-invoice-v1.1-blocked.md`). در نتیجه field set، نوع/قواعد، الزام/اختیار و مرجع expected-valueهای v1.1 معلوم نیست؛ انتخاب آن‌ها در harness به معنی ساختن قرارداد و معیار از روی حدس خواهد بود.

مولد E-41 فقط geometry و برچسب‌های عددی ساختگی را برای تست تکرارپذیری و تشخیص grid فراهم می‌کند. تست‌های آن **دقت استخراج عددی را اندازه نمی‌گیرند**. نتیجه‌های E-31 نیز به fixtureهای موجود و مسیر v0 مربوط‌اند و به‌عنوان نمونه یا دقت v1.1/synthetic بازتعبیر نمی‌شوند. بنابراین E-42 هیچ accuracy percentage، numerator/denominator یا جدول دقتِ ادعایی منتشر نمی‌کند و harness ناقص را PASS اعلام نمی‌کند.

برای رفع blocker، ابتدا مرجع مصوب Canonical Invoice v1.1 و expected-valueهای syntheticِ متصل به همان fieldها فراهم شود؛ سپس harness مستقل، اجرای تکراری، جدول metrics و CI کامل بر مبنای آن مرجع قابل تعریف است. تا آن زمان نتیجهٔ E-42 **BLOCKED** است.
